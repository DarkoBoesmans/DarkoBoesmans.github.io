## Understanding the Domain

Financial trading dashboards are among the most demanding interfaces to design. Users need to:

- Process vast amounts of real-time data
- Make split-second decisions under pressure
- Monitor multiple data streams simultaneously
- Maintain accuracy despite cognitive load

### User Research Insights

Through ethnographic research with traders, we discovered:

> "I don't need prettier charts. I need to know *now* if my position changed."

This insight drove our entire design philosophy: **clarity over beauty, speed over features**.

## Technical Architecture

### Real-Time Data Pipeline

```typescript
// WebSocket handler with automatic reconnection
class MarketDataStream {
  private ws: WebSocket | null = null;
  private reconnectAttempts = 0;
  
  connect() {
    this.ws = new WebSocket('wss://api.investtech.be/stream');
    this.ws.onmessage = (event) => this.handleMessage(event);
    this.ws.onclose = () => this.scheduleReconnect();
  }
  
  private handleMessage(event: MessageEvent) {
    const data = JSON.parse(event.data);
    // Update store with minimal re-renders
    store.batchUpdate(data);
  }
}
```

### Performance Optimizations

1. **Virtual Scrolling**: Only render visible rows in data tables
2. **Memoization**: Cache expensive calculations using WeakMap
3. **Web Workers**: Offload chart rendering to background threads
4. **Delta Updates**: Only transmit changed values over WebSocket

Creating accessible data visualizations required innovative solutions:

### Colorblind-Friendly Palette

We tested all visualizations with simulators and actual colorblind users:

- Avoided red/green distinctions
- Used patterns and shapes as secondary encodings
- Provided high-contrast mode toggle

## Key Learnings

1. **Domain knowledge is crucial**: You can't design for traders without understanding trading
2. **Performance is non-negotiable**: Milliseconds matter in financial contexts
3. **Accessibility benefits everyone**: Features designed for disabilities often improve UX for all users
